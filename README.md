## 🚀 Run Locally

### Clone the repository

```bash
git clone https://github.com/salman-devX/salmandev.git
cd salmandev
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

The development server normally runs at:

```text
http://localhost:5173
```

## 🏗️ Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
