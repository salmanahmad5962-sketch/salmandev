## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/salmanahmad5962-sketch/salman-ahmad-web-dev-platform.git
```

```bash
cd salman-ahmad-web-dev-platform
```

### 2. Install dependencies

Make sure Node.js and npm are installed.

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Vite will provide a local URL, normally:

```text
http://localhost:5173
```

Open that URL in your browser.

---

## 🏗️ Build for Production

Create an optimized production build:

```bash
npm run build
```

The production files will be generated inside:

```text
dist/
```

To preview the production build locally:

```bash
npm run preview
```

## 🚀 Deploy to GitHub Pages

This project includes a GitHub Actions workflow for deployment.

### Step 1 — Create a GitHub repository

Create a repository on GitHub.

For example:

```text
salman-ahmad-web-dev-platform
```

### Step 2 — Push the project

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/salmanahmad5962-sketch/salman-ahmad-web-dev-platform.git
git push -u origin main
```

### Step 3 — Enable GitHub Pages

Go to:

**GitHub Repository → Settings → Pages**

Under **Build and deployment**, select:

**Source → GitHub Actions**

The included workflow will build and deploy the website automatically.

### Step 4 — Open the deployed website

After the GitHub Actions workflow finishes, GitHub will provide your live website URL.

## ✏️ Editing Website Content

Most of the website content can be edited directly from:

```text
src/App.jsx
```

Important content sections/constants include:

```text
SERVICES
PROCESS_STEPS
PORTFOLIO_PROJECTS
SKILLS
WHY_POINTS
TECHNOLOGIES
FAQS
WEBSITE_TYPES
BUDGET_RANGES
FEATURE_OPTIONS
```

Your contact details are also stored in `App.jsx`:

```text
WHATSAPP_NUMBER
EMAIL_ADDRESS
LINKEDIN_URL
GITHUB_URL
```

### Adding Portfolio Projects

The portfolio currently contains placeholder project slots.

Replace the placeholder entries in:

```text
PORTFOLIO_PROJECTS
```

with your actual projects.

Each project can contain:

- Title
- Category
- Description
- Technologies
- Live demo URL
- GitHub URL

setting.

Animations should be reduced/frozen for users who prefer less motion.
